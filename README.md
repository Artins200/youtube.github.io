# YouTube Mobile Offline Clone

Точная 1:1 копия мобильного интерфейса YouTube (для смартфонов и PWA), работающая полностью локально и без доступа к интернету.

## 🚀 Основные возможности

1. **Точный дизайн YouTube Mobile (1:1):**
   - Темная тема YouTube (`#0f0f0f`, `#212121`, `#272727`, `#ff0000`, фирменный шрифт и оригинальные SVG-иконки).
   - Поддержка светлой темы (кнопка переключения на верхней панели).
   - Верхний хедер: официальный логотип YouTube, иконки трансляции (Cast), колокольчик уведомлений, полнотекстовый поиск и аватар профиля.
   - Горизонтальная лента категорий-чипов («Все», «Мои видео», «Наука», «Обучение», «Музыка», «Лайфхаки», «Животные»).
   - Нижняя навигационная панель YouTube: **Главная**, **Shorts**, **(+) Создать**, **Подписки**, **Вы**.

2. **Разделение на Обычные видео и Shorts:**
   - **Главная лента:** карточки горизонтальных видео (16:9) с плашкой хронометража, аватаром, названием, просмотрами, датой и меню действий.
   - **Карусель Shorts на главной:** горизонтальная полка с вертикальными роликами 9:16.
   - **Выделенный раздел Shorts:** полноэкранный рилс-плеер с автозацикливанием, свайпами вверх/вниз, кнопками Лайк, Дизлайк, Комментарии, Поделиться и вращающимся диском с музыкой.

3. **Полноценный видеоплеер с управлением:**
   - Перемотка на 10 секунд назад и вперед.
   - **Ускорение видео (0.25x, 0.5x, 0.75x, 1x Обычная, 1.25x, 1.5x, 1.75x, 2x)** через меню настроек и быстрый бейдж на плеере.
   - Интерактивный красный ползунок перемотки (scrubber) с индикатором буферизации.
   - На весь экран (Fullscreen).
   - Кнопки лайка, дизлайка, подписки на канал, разворачивающееся описание и блок комментариев с возможностью добавления своих комментариев.

4. **Локальная публикация видео (+):**
   - Возможность загрузить любое видео с телефона или компьютера через кнопку **(+)**.
   - Автоматическое определение ориентации (горизонтальное 16:9 → Обычное видео, вертикальное 9:16 → Shorts).
   - Автоматическое создание превью (thumbnail) из первого кадра видео.
   - Кнопка «Сгенерировать тестовое видео в 1 клик» для быстрой проверки без необходимости искать файл.
   - Сохранение видео в базу данных **IndexedDB** прямо в память браузера смартфона.

5. **100% Оффлайн-работа:**
   - Никаких внешних CDN или шрифтов — все стили, скрипты и SVG встроены локально.
   - Service Worker кэширует оболочку приложения.
   - Видеофайлы хранятся как бинарные Blob в IndexedDB устройства и никогда не передаются в интернет.

## 📱 Способы запуска и использования на телефоне

### Способ 1. Установка как PWA (Веб-приложение на экран «Домой») — САМЫЙ УДОБНЫЙ
Приложение содержит `manifest.json` и Service Worker, что позволяет установить его как настоящее приложение:
- **На iPhone (iOS / Safari):**
  1. Откройте ссылку в браузере Safari.
  2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
  3. Прокрутите и выберите **«На экран «Домой»»** (Add to Home Screen).
  4. Нажмите «Добавить». На рабочем столе появится иконка YouTube. При запуске оно откроется во весь экран без адресной строки браузера и работает без интернета!
- **На Android (Chrome / Яндекс):**
  1. Откройте ссылку в браузере Chrome.
  2. Нажмите меню из трех точек в правом верхнем углу.
  3. Выберите **«Установить приложение»** или **«Добавить на главный экран»**.

### Способ 2. Локальный сервер на компьютере в домашней Wi-Fi сети
1. Запустите на компьютере:
   ```bash
   node server.js
   ```
2. Узнайте локальный IP компьютера (например, `192.168.1.50`).
3. На телефоне, подключенном к той же сети Wi-Fi, откройте `http://192.168.1.50:3000`.

### Способ 3. Автономный запуск на самом смартфоне (без ПК)
- **На Android:** можно запустить Node.js или обычный локальный HTTP-сервер через приложение **Termux** (`pkg install nodejs && node server.js`) или приложение **Simple HTTP Server** из Google Play.
- **Обертка в нативный APK/IPA:** проект готов к компиляции в единый APK-файл через **Capacitor** (`npx cap add android`) или **Cordova**.

## 🛠 Запуск проекта

```bash
# Запуск веб-сервера (порт 3000)
node server.js
# или
npm start
```
Приложение станет доступно по адресу `http://localhost:3000`.
