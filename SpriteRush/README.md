# СПРАЙТ-РАШ (SpriteRush) — игра для MIT App Inventor

Готовый проект `.aia`: на экране **только холст (Canvas) и спрайты** — ни одной кнопки и ни одного
лейбла. Всё, включая счёт и надписи, рисуется прямо на холсте.

## Правила игры

1. На стартовом экране жмёте по большой круглой кнопке-спрайту — игра начинается.
2. На холсте появляется **много одинаковых спрайтов** (`target.png`).
3. У каждого появившегося спрайта своё время жизни: на 1 уровне это **5 секунд**.
   Если за это время по спрайту не нажали — **игра окончена**, таймер останавливается.
4. Нажали — спрайт **исчезает на 3 секунды**, а потом появляется снова в случайном месте.
5. Игра **бесконечная**: каждые 8 секунд повышается уровень, и становится сложнее:
   * больше целей одновременно (3 → 24);
   * меньше времени на нажатие (5.0 с → 1.5 с);
   * со 2-го уровня спрайты начинают двигаться (скорость растёт до предела).
6. Рекорд сохраняется в TinyDB и показывается на стартовом экране.

## Как установить

1. Скачайте **`SpriteRush.aia`** (лежит рядом с этим файлом).
2. Зайдите на [ai2.appinventor.mit.edu](https://ai2.appinventor.mit.edu) → **Projects → Import project (.aia) from my computer**.
3. Выберите файл, подождите импорт → **Connect → AI Companion** (или соберите APK).
4. Готово: в проекте 1 экран, 28 компонентов и ~1670 блоков — всё уже настроено.

> App Inventor сам перепишет пути и настройки проекта под вашего пользователя —
> это нормально, после импорта проект сохранится в вашем аккаунте.

## Как заменить картинки на свои

В игре три картинки, все лежат в `Media` (ассетах) проекта:

| Файл | Что это | Рекомендуемый размер |
|---|---|---|
| `target.png` | цель, по которой надо нажимать (её копии — 24 спрайта) | 128×128, с прозрачностью |
| `start.png` | круглая кнопка «старт» | 256×256, с прозрачностью |
| `back.png` | фон холста | 480×800, любой |

**Важно:** загружайте свои картинки **с теми же именами** (`target.png`, `start.png`, `back.png`) —
тогда ничего править в блоках не нужно. В App Inventor: раздел **Media → Upload File**.
Если зальёте файл с другим именем — просто поменяйте свойство `Picture` у спрайтов
(выделите `Sprite1…Sprite24` — у них общее свойство `Picture`) и `BackgroundImage` у `Canvas1`.

Размер самих спрайтов меняется в дизайнере: у всех `Sprite1…Sprite24` свойства
`Width` и `Height` = **64** пикселя (у `SpriteStart` — 180).

### Компоненты

| Компонент | Зачем |
|---|---|
| `Canvas1` | весь игровой экран; на нём рисуются надписи, к нему привязаны спрайты |
| `Sprite1 … Sprite24` | 24 одинаковых спрайта (пул целей) — `Picture = target.png`, 64×64 |
| `SpriteStart` | кнопка старта/рестарта (тоже спрайт, `start.png`, 180×180, слой Z=10) |
| `Clock1` | таймер, тикает каждые 100 мс |
| `TinyDB1` | хранит рекорд |

### Блоки

**Глобальные переменные:** `playing`, `over`, `score`, `best`, `gameTime`, `secCounter`,
`tickInSec`, `level`, `levelUpAt`, `lifeTime`, `respawnDelay`, `maxActive`, `speed`, `active`,
`poolSize` и три списка состояния: `visibleList` (виден ли спрайт), `bornList` (когда появился),
`respawnList` (когда можно появиться снова).

**Процедуры:**

| Процедура | Что делает |
|---|---|
| `InitLists` | создаёт списки состояния по 24 элемента |
| `HideAll` | прячет все 24 спрайта |
| `SetAllSpeed` | задаёт скорость всем спрайтам при повышении уровня |
| `Spawn(index)` | ставит спрайт №index в случайное место, задаёт курс/скорость, показывает |
| `UpdateDifficulty` | повышает уровень и пересчитывает `maxActive`, `lifeTime`, `speed` |
| `DrawHUD` | очищает холст и рисует интерфейс (счёт / уровень / время / «игра окончена») |
| `GameOver` | останавливает таймер, прячет цели, сохраняет рекорд, показывает экран конца |
| `StartGame` | сбрасывает всё и запускает игру |

**События:** `Screen1.Initialize`, `Clock1.Timer` (вся логика игры), `SpriteStart.Touched`
(старт/рестарт) и `Sprite1.Touched … Sprite24.Touched` (нажатие по цели).

## Как поменять настройки игры

Два способа.

**Способ 1 — прямо в блоках (быстро).** Основные параметры лежат в глобальных переменных,
их видно и можно менять в редакторе блоков: `lifeTime` (сколько живёт цель),
`respawnDelay` (3 с паузы после нажатия), `levelUpAt` (через сколько мс новый уровень),
`maxActive`, `speed`, `poolSize`. Формулы роста сложности собраны в процедуре
`UpdateDifficulty` — числа `8000`, `250`, `1500`, `0.8`, `10` правятся прямо в ней.

**Способ 2 — пересобрать проект (надёжно).** Все константы лежат в начале
`tools/build_aia.py`:

```python
POOL = 24            # сколько всего спрайтов на холсте
START_ACTIVE = 3     # целей одновременно на 1 уровне
LEVEL_UP_MS = 8000   # новый уровень каждые 8 с
ACTIVE_PER_LEVEL = 1 # +1 цель за уровень
BASE_LIFE_MS = 5000  # 5 с на нажатие
LIFE_STEP_MS = 250   # −0.25 с за уровень
MIN_LIFE_MS = 1500   # предел
RESPAWN_MS = 3000    # спрайт пропадает на 3 с
SPEED_STEP = 0.8     # рост скорости за уровень
MAX_SPEED = 10
SPRITE_PX = 64       # размер спрайта
```

После правки запустите:

```bash
python3 tools/build_aia.py --check   # пересобрать .aia и проверить
python3 tools/simulate.py            # проиграть партию в консоли и убедиться, что логика жива
```

Имейте в виду: количество спрайтов задаётся в дизайнере, поэтому при смене `POOL`
проект нужно пересобрать скриптом (он сам создаст нужное число компонентов).

## Проверено

* `.aia` собирается по официальному формату MIT App Inventor
  (`project.properties` + `Screen1.scm` + `Screen1.bky` + `assets/`).
* `tools/simulate.py` проигрывает блоки как программу:
  * игрок, который не нажимает, проигрывает через **5.2 с** (5 с жизни + шаг таймера);
  * «живой» игрок дошёл до **16 уровня**, 602 очка, 24 цели, скорость 10.
